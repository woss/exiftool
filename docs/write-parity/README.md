## `matrix.json` — the contract

Generated by `pnpm generate-matrix` from `vendor/exiftool/README` +
`src/tags/generated/manifest.json`. Never hand-edit the generated sections
(`fileTypes`, `families`, `exiftoolVersion`); promote a cell by editing the
`PARTIALS`/override data in `scripts/generate-matrix.ts` **and** adding the
test it points at, in the same lane.

| Key | Meaning |
|---|---|
| `fileTypes` / `families` | Upstream `r` / `r/w` / `r/w/c` exactly as vendored. `r` ⇒ `status: read-only`, never a write target. |
| `cells` | Sparse overrides keyed `fileType\|family\|op`, op ∈ `set delete copy create preserve`. Absent ⇒ default `not-started` (writable) or `read-only` (upstream `r`). |
| `status` | `implemented \| partial \| read-only \| unsafe \| not-started`. |
| `implemented` | Requires a non-null `test` (CI rejects otherwise). |
| `partial` / `unsafe` | Require a non-null `reason`. |
| `fixture` | Redistributable fixture path when the cell needs one; see `fixtures/README.md`. |

Reading the matrix: a container's writeability does **not** imply every
family writes into it. Only cells present in `cells` claim anything today;
everything else is `not-started` by default.

test vectors, exit gate. A lane that cannot state the invariants stays
`not-started`/`unsafe` with a reason.

## Agent workflow (one lane = one cell cluster)

1. Planner (read-only): `get_minimal_context` on the graph, produce the spec
   delta + matrix cell(s) to flip. No code.
2. Implementer: one GitButler lane, one serializer **or** one container **or**
   one op cluster. Differential test before status promotion.
3. Reviewer: our-write→upstream-read, upstream-write→our-read, unchanged
   blocks byte-identical. Refuse ambiguous/unsafe offsets loud.

```bash
pnpm generate-matrix            # regenerate docs/write-parity/matrix.json
pnpm generate-matrix --check    # CI: checked-in matrix must match generator
pnpm generate-tags              # regenerate src/tags/generated/* (never hand-edit)
```

## Divergences

Known deliberate differences live in `DIVERGENCES.md` (read side) and in
matrix `reason` strings (write side). A new divergence needs both entries
before the cell can claim `implemented`.
